聚水潭安全打单助手 V0.5.25：Windows 源码备用运行

一、准备
完整解压源码。在 client 中将 jst_operator_config.example.json 复制为 jst_operator_config.json，保持 backend_mode=local。聚水潭三项真实查询凭据另行放在 %USERPROFILE%\.jst-auto-print\jst_openapi_config.json，或配置 JST_APP_KEY / JST_APP_SECRET / JST_ACCESS_TOKEN。

二、源码运行
源码入口要求 Python 3.10 x64、Python Launcher 和 Tcl/Tk；无需 conda。双击 Win10_21H1_源码直接启动.bat，脚本会创建独立环境、安装完整哈希锁定依赖并以不打印模式启动。单机配置无需原后台地址或 Bearer Token。“不打印”仍可能改快递和获取真实运单号。

三、构建和安装包
双击 build_jst_auto_print_win10_x64.bat。只有全部构建门禁、EXE 离线自检、ZIP 和 SHA256 检查通过后才可交付。Setup 需再用 Inno Setup 6.3 或更新版本编译 jst_auto_print_installer.iss；所需 ChineseSimplified.isl 语言文件应已安装。安装后的软件无需 Python 或 conda。

四、切换和验收
保留已有本机任务记录，另行核对原服务器独有的永久跳过数据。单机模式不连接旧协调后台。确认有效聚水潭凭据、专用浏览器登录和打印组件后，再完成真实接口、安装和一单实体纸张验收。详细步骤及当前验证边界见 Windows版打包说明.md。
